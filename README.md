# ATMORA – Human Resource Management System (HRMS)

## Project Overview

ATMORA is a centralized, multi-tenant Human Resource Management System designed to simplify and streamline an organization's complete employee lifecycle.

The platform provides an integrated environment for managing employee information, attendance, leave, payroll, assets, approvals, recruitment, performance, employee issues, and administrative operations.

ATMORA follows a controlled, sales-led onboarding model where companies are registered and provisioned by the ATMORA Super Admin after the demo and evaluation process.

## Core Modules

The platform consists of the following modules:

- **People Management:** Employee profiles, employee directory, workforce KPIs, tenure tracking, anniversaries, and organizational hierarchy.
- **Attendance Management:** Shift management, holidays, work modes, office-day policies, regularization, overtime, and timesheets.
- **Leave & Payroll:** Leave administration, salary components, statutory rules, tax slabs, payroll calculations, and financial adjustments.
- **Asset Management:** Asset allocation, tracking, renewals, expiry reminders, and employee ID card management.
- **Approvals:** Centralized approval engine, workflow designer, and unified Approvals Center.
- **Letters:** Document templates, PDF generation, approval workflows, and employee letter management.
- **Issues:** Employee issue reporting, configurable categories, routing, escalation, and anonymous reporting.
- **Recruitment:** Recruitment and candidate management.
- **Employee Exit:** Employee separation, clearance, and asset return management.
- **Performance:** Employee performance tracking and evaluation.
- **Staff Welfare:** Employee welfare-related activities and initiatives.
- **Administration:** Masters, user roles, integrations, company settings, subscriptions, and centralized policy management.

## User Roles

ATMORA supports five primary user roles:

| Role | Description |
|---|---|
| Super Admin | Platform-level administration, company provisioning, subscriptions, module management, and support access. |
| Company Admin | Company-level administration and configuration. |
| HR | Employee lifecycle and HR operations management. |
| Manager | Team-level employee and operational access. |
| Employee | Access to personal employee information and self-service functionality. |

## Key System Capabilities

- Multi-tenant company management.
- Role-based access control.
- Company-specific module activation.
- Centralized approval workflows.
- Configurable Masters and Policy Engine.
- Hierarchical policy application with specificity-based priority.
- Policy version management.
- Integrated employee lifecycle management.
- Controlled company onboarding and go-live process.
- Audited Super Admin support access.

## Important Implementation Notes

- Companies are provisioned by the ATMORA Super Admin; public self-registration is not supported.
- Employee creation is enabled only after company setup and go-live.
- Overtime is maintained within the Attendance module.
- ID cards are managed as an asset type within Asset Management.
- Timesheet tasks currently use four predefined demo values and are not linked to project management.
- Email functionality is currently a placeholder.
- Subscription billing is handled outside the platform.
